# Student Management System – React Components, JSX & Props

A simple React application created to demonstrate the use of **React Components, JSX, JavaScript expressions, Props, and Component Reusability**.

## Features

- Header component displaying the Student Management System title
- Reusable `StudentProfile` component
- Student details passed using props
- JSX expressions used to display student information
- CSS styling with borders and padding
- Footer component with copyright information

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/student-management-react.git
```

### 2. Navigate to the project folder

```bash
cd student-management-react
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in the browser

After running the command, Vite will display a local URL such as:

```text
http://localhost:5173/
```

Open the URL in your browser to view the application.
